# Evidencia Scrum

Guardar aquí la evidencia de cada ceremonia (vale 7 pts de la rúbrica):

- `sprint-N-planning.md` — fecha, objetivo del sprint, historias comprometidas.
- `dailies.md` — notas breves de las dailies asincrónicas (mínimo 3 por semana).
- `sprint-N-review-retro.md` — qué se completó, demo interna, qué mejorar.

El tablero de GitHub Projects y los milestones son la evidencia principal;
esto complementa con las ceremonias.
